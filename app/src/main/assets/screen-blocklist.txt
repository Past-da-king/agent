# Background screen: apps the agent may never open, see or touch.
# Banking, wallets, payments, cards, crypto and investing. Money stays in the person's own hands.
#
# The rules in this file are built in: nobody can switch them off, not the person, not the agent.
# People can only ADD apps (Settings > Background screen > Blocked apps).
#
# One rule per line:
#   com.example.app          an exact package
#   com.example.*            a package pattern (* is any run of characters)
#   word:bank                any package with a dot-separated part that contains this word
#   edge:pay                 any package with a part that starts or ends with this word
#   label:capitec            any app whose name on the phone has this word (whole words)
#   screen:available balance words that mark a money screen when the app also hides its screen from being seen
#
# To extend it: add a line. Unit tests (ScreenBlocklistTest) check every line parses.
